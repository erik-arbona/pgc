# Planos de Estudos — EIC e TM

Fonte: Plano Curricular EIC (2023/2024) e Plano Curricular TM (fevereiro de 2024).

## Legenda das siglas

| Sigla | Significado |
|---|---|
| Área | Área Científica (art.º 14.º dos Estatutos da UniCV) |
| CETE | Ciências Exatas, Tecnologias e Engenharias |
| CHSA | Ciências Humanas, Sociais e Artes |
| CEJP | Ciências Económicas, Jurídicas e Políticas |
| CNVA | Ciências da Natureza, da Vida e do Ambiente |
| T | Horas semanais de contacto Teóricas |
| TP | Horas semanais de contacto Teórico-Práticas |
| P/L | Horas semanais de contacto Práticas/Laboratoriais |
| Total (contacto semanal) | T + TP + P/L |
| HC | Horas de Contacto (semestrais) |
| HEA | Horas de Estudo Autónomo (semestrais) |
| Total (contacto semestral) | HC + HEA (carga horária total) |
| CTS | Créditos (unidades de crédito, ECTS) |
| Obs. | Observações |
| UC | Unidade Curricular |
| UCT | Unidade Curricular Terminal |
| PFC | Projeto de Fim de Curso |
| ETC | Estágio Técnico-Científico |
| AIC | Atividade de Integração Curricular |
| TIC | Tecnologias de Informação e Comunicação (percurso EIC) |
| PSI | Programação e Sistemas de Informação (percurso EIC) |
| EIC | Engenharia Informática e de Computadores |
| TM | Tecnologias Multimédia |
